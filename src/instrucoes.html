🚀Como Iniciar

⚠️ Importante: Esta aplicação precisa rodar em um servidor local para funcionar corretamente. Não abra o arquivo HTML diretamente!

Opção 1: Python (Recomendado)

# Navegue até a pasta do projeto
cd caminho/para/o/projeto

# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Acesse: http://localhost:8000

Opção 2: Node.js

# Instale o http-server (apenas uma vez)
npm install -g http-server

# Inicie o servidor
http-server -p 8000

# Acesse: http://localhost:8000

Opção 3: VS Code Live Server

  1. Instale a extensão "Live Server" no VS Code
  2. Clique com botão direito em index.html
  3. Selecione "Open with Live Server"

🎨Paleta de Cores

Este projeto segue rigorosamente a Regra 60-30-10:

  • 60% Wheat (#F5DEB3) - Cor dominante/base
  • 30% Brown (#8B4513) - Cor secundária/contraste
  • 10% Branco (#FFFFFF) - Cor de destaque/acento
  • Cores de apoio: Cinza e Preto

🎯Fóruns Temáticos

1. Primeira Infância (0-3 anos)

Desenvolvimento motor, alimentação, sono, amamentação e primeiros passos.

2. Pré-escola (4-6 anos)

Alfabetização, socialização, comportamento e preparação escolar.

3. Adolescência

Comunicação, autonomia, saúde mental e redes sociais.

4. Necessidades Especiais

TEA, TDAH, inclusão escolar, terapias e direitos.

🐛Debug Mode

Em ambiente local, você pode usar o console do navegador (F12) para debug:

// Ver estado atual
console.log(window.appDebug.state);

// Criar toast
window.appDebug.showToast('Teste!', 'success');

// Forçar re-render
window.appDebug.render();
